# Kitty Mesh =^..^=

## Register

product

## Users
Developers and curious visitors using a webcam in a modern browser. They test face, body, hand, and finger recognition, then inspect the actual code behind the result.

## Product Purpose
Recognize states locally, keep the camera stable while scores update, and let the user open the real bundled source from Explorer.

## Brand Personality
Dark, compact, practical, and a little feline. The interface resembles a late-1990s desktop IDE with plain panes, file paths, status text, and crimson active state.

## Anti-references
No marketing page, cyberpunk dashboard, glass interface, gradients, glows, ornamental circuitry, oversized headings, rounded cards, fake logs, or unused reaction screen.

## Design Principles
1. Keep the camera, device control, and source inspection close at paw.
2. Use familiar desktop IDE controls.
3. Show only real source and runtime values.
4. Keep camera processing on the device.
5. Prevent live data from changing pane dimensions.

## Accessibility & Inclusion
Target WCAG 2.2 AA. Preserve visible keyboard focus, sufficient contrast, readable status text, semantic buttons, and usable controls on touch devices. Respect reduced motion. Sound is optional and off by default.
