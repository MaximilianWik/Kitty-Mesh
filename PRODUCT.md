# Face Mesh

## Register

product

## Users
Developers and curious visitors using a webcam in a modern browser. They want to test expression and pose recognition and inspect what the application is doing.

## Product Purpose
Recognize six face and body states locally, show the current scores and execution path, and display the matched pose in a separate output view.

## Brand Personality
Direct, compact, utilitarian. The interface should resemble a late-1990s desktop IDE: plain panes, file tabs, status text, and visible source paths.

## Anti-references
No marketing landing page, cyberpunk dashboard, glass interface, gradients, glows, ornamental circuitry, oversized headings, rounded cards, fake terminal output, or novelty-filter styling.

## Design Principles
1. Keep the camera and matched output easy to find.
2. Use standard desktop IDE structure and controls.
3. Show only real runtime events and source lines.
4. Keep all camera processing on the device.
5. Prefer short labels over explanatory copy.

## Accessibility & Inclusion
Target WCAG 2.2 AA. Preserve visible keyboard focus, sufficient contrast, readable status text, semantic tabs, and 44px controls where touch is likely. Respect reduced-motion preferences. Audio remains optional and off by default.
